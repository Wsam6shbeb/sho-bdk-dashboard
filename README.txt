لوحة تحكم شو بدك — نسخة تصميم أولية

مهم:
- هذه الملفات تعرض التصميم فقط ولا تتصل بـ Supabase بعد.
- لا تدخل كلمات مرور أو مفاتيح سرية في ملفات الواجهة.
- لا تفعّل لوحة التحكم للاستخدام الحقيقي قبل إضافة تسجيل دخول المدير والتحقق من الصلاحيات في قاعدة البيانات.

المحتويات:
- index.html: الصفحة الرئيسية
- styles.css: التصميم
- app.js: التنقل بين الصفحات

الخطوة التالية بعد معاينة التصميم:
إضافة تسجيل دخول آمن للمدير ثم ربط إعداد العمولة بـ Supabase عبر صلاحيات قاعدة البيانات.
